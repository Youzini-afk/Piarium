# Workbench extension examples

These examples are generated by `@piarium/extension-cli` and are meant to live outside this
monorepo. Do not import `@piarium/ui` or any Piarium product React module.

```sh
npx @piarium/extension-cli init ./vanilla-shell --id dev.example.vanilla-shell --name "Vanilla Shell" --template shell
npx @piarium/extension-cli init ./custom-editor --id dev.example.custom-editor --name "Custom Editor" --template editor
npx @piarium/extension-cli init ./sidebar-view --id dev.example.sidebar-view --name "Sidebar View" --template view
npx @piarium/extension-cli init ./language-provider --id dev.example.markdown-language --name "Markdown Language" --template language
```

Each project can `npx piarium-extension build` and `npx piarium-extension test` after installing the
public SDK packages. Isolated document edits use the granted `workspace.documents` capability;
disable destroys the isolated realm and leaves Core document/layout state in place.

The coordinated public version for this workbench SDK is 0.2.0. Do not npm tag or publish until that
release is explicitly approved.
