# Variáveis de ambiente

O Piarium lê estas variáveis de ambiente na inicialização. Para serviços de inicialização, `piarium startup enable` salva por padrão um snapshot do ambiente atual, então execute de novo depois de alterar as variáveis que o serviço deve usar.

O Piarium incorpora o runtime Pi. Não há um servidor OpenCode separado nem variáveis de integração `OPENCODE_*`.

## Servidor Piarium

### `PIARIUM_HOST`

Endereço de bind do servidor web do Piarium. Use `0.0.0.0` para permitir acesso de outras máquinas.

### `PIARIUM_UI_PASSWORD`

Senha da UI do navegador. Use ao fazer bind fora de localhost, ao usar túneis ou ao rodar atrás de um proxy reverso.

### `PIARIUM_API_ONLY`

Inicia o Piarium em modo headless quando definido como `true` ou `1`. As rotas de API continuam disponíveis para clientes desktop e mobile, mas a UI do navegador não é servida.

### `PIARIUM_DATA_DIR`

Substitui o diretório de dados do Piarium. O padrão é `~/.config/piarium`.

### `PIARIUM_COMPRESS_API`

Controla a compressão das respostas da API. Use `true` ou `1` para forçar a ativação, `false` ou `0` para forçar a desativação.

### `PIARIUM_SKIP_API_COMPRESSION`

Desativa a compressão das respostas da API quando definido como `true` ou `1`. Isso tem precedência sobre `PIARIUM_COMPRESS_API`.

### `PIARIUM_VERBOSE_REQUEST_LOGS`

Ativa logs HTTP detalhados quando definido como `true` ou `1`.

### `PIARIUM_UPDATE_API_URL`

Substitui o endpoint da API de verificação de atualizações. A maioria das pessoas deve deixar isso sem definir.

### `PIARIUM_PACKAGE_MANAGER`

Força o gerenciador de pacotes usado pelas operações de atualização quando a detecção automática está errada.

## Terminal e Git

### `PIARIUM_TERMINAL_SHELL`

Executável de shell usado nas sessões de terminal do Piarium.

### `PIARIUM_GIT_BINARY`

Executável do Git usado pelos recursos de Git do Piarium.

### `GIT_BINARY`

Outra substituição do executável do Git. Prefira `PIARIUM_GIT_BINARY` para configuração específica do Piarium.

### `PIARIUM_GIT_READ_CACHE_TTL_MS`

Tempo de vida, em milissegundos, das leituras de arquivo em cache baseadas em Git. Defina `0` para desativar este cache ao depurar.

## Voz e túneis

### `OPENAI_API_KEY`

Chave de API usada pelos recursos de voz do Piarium que chamam serviços compatíveis com OpenAI.

### `PIARIUM_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Permite URLs base remotas compatíveis com OpenAI para recursos de voz quando definido como `true` ou `1`.

### `NGROK_AUTHTOKEN`

Token de autenticação do ngrok usado pelos comandos de túnel do Piarium. Você também pode configurar o ngrok com `ngrok config add-authtoken <token>`.

## Ajudantes de runtime

### `BUN_BINARY`

Executável do Bun que o Piarium deve usar ao iniciar processos daemon.

### `BUN_INSTALL`

Raiz de instalação do Bun. O Piarium usa isso para encontrar `bin/bun` na inicialização do daemon e nas atualizações.
