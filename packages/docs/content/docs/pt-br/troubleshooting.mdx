# Solução de problemas

Deu ruim? Encontre o sintoma abaixo e tente a correção.

## O comando do Piarium sai ou não inicia

- confirme Node.js `>=22.19` (Node.js 24 é a linha de base de desenvolvimento suportada)
- a partir de um checkout de código-fonte, execute `bun run dev` ou `bun run start:web`
- se você tiver uma CLI publicada, execute `piarium --version` e reinstale se precisar

## A UI web não está acessível

- a partir de um checkout de código-fonte, leia o terminal que iniciou `bun run dev`
- se você tiver uma CLI publicada, verifique os logs do servidor com `piarium logs`
- verifique a porta ativa (o desenvolvimento usa a URL do Vite; o padrão do servidor é `3000`)
- abra `http://localhost:3000` diretamente primeiro antes de testar links de túnel

## O link remoto/túnel não funciona

- execute `piarium tunnel status --all` quando a CLI estiver instalada
- reinicie o túnel a partir da mesma instância/porta
- regenere o link de conexão se o token anterior já tiver sido usado

Veja [Túneis](/pt-br/tunnels/) para a configuração completa, e [Proxy reverso](/pt-br/reverse-proxy/) se você usar um.

## A extensão do VS Code não conecta

- confirme que o servidor do Piarium está em execução
- reconstrua ou atualize a extensão a partir deste repositório
- recarregue a janela do VS Code e tente a conexão de novo
