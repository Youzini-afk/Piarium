# Início rápido

## Caminho mais rápido

1. Clone o [Varin](https://github.com/Youzini-afk/Varin) e instale as dependências com Bun (veja [Instalação](/pt-br/install/)).
2. Execute `bun run dev`.
3. Abra a URL do Vite impressa no terminal.
4. Para usar no celular, inicie um [túnel](/pt-br/tunnels/) e escaneie o QR code.

Você deve ver a lista de sessões do Varin no navegador. Se ela carregar, está tudo pronto.

Se preferir um container, use o caminho Docker em [Instalação](/pt-br/install/) e abra `http://127.0.0.1:3000` com o `VARIN_UI_PASSWORD` gerado.

Use uma senha de UI forte, principalmente se pretende abrir a instância para a internet.

Se a página não carregar, veja [Solução de problemas](/pt-br/troubleshooting/).

## Qual app eu devo usar?

- use o **desktop** para o trabalho local do dia a dia (`bun run electron:dev`)
- use a **web** para acesso remoto e revisão no celular
