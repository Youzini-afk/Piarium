# Ferramenta de controle do agente

Use a ferramenta de controle do agente do Varin para gerenciar o trabalho no app diretamente pelo chat. Ela está disponível no desktop e na web quando o Varin está executando o runtime Pi local. Não há ferramenta separada para instalar nem comando de shell para executar.

## O que você pode pedir

Peça ao agente em linguagem natural. Por exemplo:

- "Crie uma nova sessão do Varin neste projeto, use o modelo `openai/gpt-5.6-sol` e envie este prompt: revise o fluxo de autenticação."
- "Crie uma nova sessão do Varin para esta tarefa em um worktree separado e peça para adicionar testes ao fluxo de login."
- "Use o Varin para listar minhas 10 sessões mais recentes e incluir o status atual delas."
- "Crie uma tarefa agendada do Varin chamada Weekday review que envie este prompt às 09:00 em todo dia útil: revise as mudanças desde a última execução."
- "Execute agora a tarefa agendada do Varin chamada Weekday review."
- "Verifique a sessão do Varin chamada Authentication review e mostre a última resposta do assistente."

A ferramenta pode listar projetos e preferências de modelo, criar sessões e dar continuidade, ramificar uma sessão, criar sessões de worktree isoladas e gerenciar tarefas agendadas. Sessões iniciadas assim aparecem no Varin como qualquer outra, então você pode abri-las e continuar o trabalho.

## Tenha em mente

- Prompts de nova sessão retornam imediatamente por padrão. Acompanhe a sessão no Varin ou peça ao agente para verificá-la depois.
- Um worktree separado só é criado quando você pede um. Alterações não commitadas do worktree atual não são copiadas para ele.
- A ferramenta não pode excluir sessões ou worktrees, registrar caminhos de projeto, executar comandos de shell arbitrários nem chamar URLs arbitrárias.

## Ligar ou desligar a ferramenta

Abra **Settings**, altere **Agent control tool** e salve. A configuração se aplica ao runtime atual do Varin.
