# Documentação do Varin

O Varin é um espaço de trabalho independente para Agents e um harness completo para programação, pesquisa e outros projetos. Inclui um runtime Pi integrado e usa diretamente o SDK do [Pi](https://github.com/earendil-works/pi), a árvore de sessões e o gerenciador de pacotes, em vez de um wrapper de terminal.

Use esta documentação para:

- instalar a plataforma certa para o seu fluxo de trabalho
- abrir o Varin para uso local ou remoto
- personalizar a aparência e resolver problemas comuns

## Para que serve o Varin

O Varin é voltado para programação, pesquisa e outros projetos que se beneficiam de um centro de controle: ramificar sessões, revisar resultados, gerenciar terminais, acompanhar o progresso das ferramentas, executar ações de projeto e manter todo o painel à vista enquanto o agente trabalha.
