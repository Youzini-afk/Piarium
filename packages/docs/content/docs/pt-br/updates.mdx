# Atualizações

Como você atualiza o Piarium depende de como o instalou. Em todos os casos, você pode ver a versão atual em **Settings → About**.

## App de desktop

O app de desktop verifica atualizações em relação às GitHub releases. Quando uma está disponível, o Piarium avisa, baixa quando você escolhe e instala na próxima reinicialização. Você sempre tem o controle — nada é instalado sem a sua autorização.

As GitHub Releases ainda não foram publicadas. Até lá, atualize um checkout de código-fonte com `git pull` e reconstrua, ou fixe um digest de container testado.

## Web / CLI

Se você instalou uma CLI publicada, atualize-a em **About** com os botões de verificar e atualizar, ou no terminal:

```bash
piarium update
```

O Piarium detecta como foi instalado (npm, pnpm, yarn ou bun) e executa a atualização certa. O pacote `@piarium/web` ainda não está no registro público do npm, então este caminho só se aplica depois que uma release for publicada.

Checkouts de código-fonte atualizam com Git. Implantações Docker atualizam ao puxar um novo digest de imagem.
