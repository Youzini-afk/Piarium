# 更新

你如何更新 Piarium 取决于你如何安装它。在任何情况下，你都可以在 **Settings → About** 查看当前版本。

## 桌面应用

桌面应用会对照 GitHub releases 检查更新。当有可用更新时，Piarium 会告诉你，在你选择时下载它，并在下次重启时安装它。一切都由你掌控 — 没有你的同意不会安装任何东西。

GitHub Releases 尚未发布。在发布之前，请用 `git pull` 更新源码检出并重新构建，或固定到已测试的容器 digest。

## Web / CLI

如果你安装的是已发布的 CLI，可以从 **About** 用检查和更新按钮更新它，或从终端更新：

```bash
piarium update
```

Piarium 会检测它是如何安装的（npm、pnpm、yarn 或 bun），并为你运行正确的更新。`@piarium/web` 包尚未上架公共 npm registry，因此这条路径仅在发布之后才适用。

源码检出用 Git 更新。Docker 部署通过拉取新的镜像 digest 来更新。
