# Varin Docs

Varin is an independent Agent workspace and full harness for coding, research, and other project work. It includes a bundled Pi runtime and uses the [Pi](https://github.com/earendil-works/pi) SDK, session tree, and package manager directly rather than wrapping a terminal UI.

Use these docs to:

- install the right app for how you work
- open Varin for local or remote use
- customize the look and fix common issues

## What Varin is for

Varin is for coding, research, and other project work that benefits from a control room: branching sessions, reviewing results, managing terminals, watching tool progress, running project actions, and keeping the full board visible while the agent works.
