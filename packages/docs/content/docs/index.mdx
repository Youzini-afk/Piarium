# Piarium 文档

Piarium 是面向编程智能体的 Pi 原生工作空间。它直接使用 [Pi](https://github.com/earendil-works/pi) SDK、会话树和包管理器 — 不是终端包装器，也不是 OpenCode 兼容层。

使用本文档来：

- 为你的工作方式安装合适的应用
- 打开 Piarium，用于本地或远程使用
- 自定义外观并排查常见问题

## Piarium 用于什么

Piarium 面向 AI 编程中那些受益于控制中枢的部分：为会话分支、审查代码差异、管理终端、观察工具进度、运行项目操作，并在智能体工作时让整个面板尽收眼底。
