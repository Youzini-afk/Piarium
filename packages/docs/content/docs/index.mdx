# Piarium Docs

Piarium is a Pi-native workspace for coding agents. It uses the [Pi](https://github.com/earendil-works/pi) SDK, session tree, and package manager directly — not a terminal wrapper and not an OpenCode compatibility layer.

Use these docs to:

- install the right app for how you work
- open Piarium for local or remote use
- customize the look and fix common issues

## What Piarium is for

Piarium is for the parts of AI coding that benefit from a control room: branching sessions, reviewing diffs, managing terminals, watching tool progress, running project actions, and keeping the full board visible while the agent works.
