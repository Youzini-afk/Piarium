# Mises à jour

La façon de mettre à jour Piarium dépend de la façon dont vous l’avez installé. Dans tous les cas, vous pouvez vérifier votre version actuelle dans **Settings → About**.

## Application desktop

L’application desktop vérifie les mises à jour par rapport aux GitHub releases. Quand une est disponible, Piarium vous le dit, la télécharge quand vous le choisissez, et l’installe au prochain redémarrage. Vous gardez toujours le contrôle — rien ne s’installe sans votre accord.

Les GitHub Releases ne sont pas encore publiées. En attendant, mettez à jour une copie source avec `git pull` et reconstruisez, ou épinglez un digest de conteneur testé.

## Web / CLI

Si vous avez installé une CLI publiée, mettez-la à jour depuis **About** avec les boutons de vérification et de mise à jour, ou depuis le terminal :

```bash
piarium update
```

Piarium détecte comment il a été installé (npm, pnpm, yarn ou bun) et lance la bonne mise à jour. Le paquet `@piarium/web` n’est pas encore sur le registre npm public, donc ce chemin ne s’applique qu’après la publication d’une release.

Les copies source se mettent à jour avec Git. Les déploiements Docker se mettent à jour en tirant un nouveau digest d’image.
