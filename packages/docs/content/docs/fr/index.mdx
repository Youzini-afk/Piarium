# Documentation Piarium

Piarium est un espace de travail natif Pi pour les agents de codage. Il utilise directement le SDK [Pi](https://github.com/earendil-works/pi), l’arbre de sessions et le gestionnaire de paquets — ce n’est ni un wrapper de terminal, ni une couche de compatibilité OpenCode.

Utilisez cette documentation pour :

- installer l’application qui correspond à votre façon de travailler
- ouvrir Piarium pour un usage local ou distant
- personnaliser l’apparence et corriger les problèmes courants

## À quoi sert Piarium

Piarium sert aux parties du codage IA qui gagnent à être pilotées depuis une salle de contrôle : sessions par branche, revue des diffs, gestion des terminaux, suivi de l’avancement des outils, lancement d’actions de projet et vue d’ensemble pendant que l’agent travaille.
