# Démarrage rapide

## Chemin le plus rapide

1. Clonez [Piarium](https://github.com/Youzini-afk/Piarium) et installez les dépendances avec Bun (voir [Installation](/fr/install/)).
2. Exécutez `bun run dev`.
3. Ouvrez l’URL Vite affichée dans le terminal.
4. Pour l’utiliser depuis votre téléphone, démarrez un [tunnel](/fr/tunnels/) et scannez le QR code.

Vous devriez voir la liste des sessions Piarium dans votre navigateur. Si elle se charge, vous êtes opérationnel.

Si vous préférez un conteneur, utilisez le chemin Docker de [Installation](/fr/install/) et ouvrez `http://127.0.0.1:3000` avec le `PIARIUM_UI_PASSWORD` généré.

Utilisez un mot de passe UI fort, surtout si vous prévoyez d’ouvrir l’instance à Internet.

Si la page ne se charge pas, consultez le [dépannage](/fr/troubleshooting/).

## Quelle application utiliser ?

- utilisez le **desktop** pour le travail local au quotidien (`bun run electron:dev`)
- utilisez le **web** pour l’accès distant et la relecture depuis votre téléphone
- utilisez **VS Code** pour des sessions juste à côté de votre code (construisez l’extension depuis les sources)
