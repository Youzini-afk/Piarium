# Szybki start

## Najszybsza ścieżka

1. Sklonuj [Varin](https://github.com/Youzini-afk/Varin) i zainstaluj zależności za pomocą Bun (zobacz [Instalacja](/pl/install/)).
2. Uruchom `bun run dev`.
3. Otwórz adres Vite wypisany w terminalu.
4. Aby używać z telefonu, uruchom [tunel](/pl/tunnels/) i zeskanuj kod QR.

W przeglądarce powinna pojawić się lista sesji Varin. Jeśli się ładuje, wszystko działa.

Jeśli wolisz kontener, użyj ścieżki Docker w [Instalacja](/pl/install/) i otwórz `http://127.0.0.1:3000` z wygenerowanym `VARIN_UI_PASSWORD`.

Używaj silnego hasła UI, zwłaszcza jeśli planujesz otworzyć instancję na internet.

Jeśli strona się nie ładuje, sprawdź [Rozwiązywanie problemów](/pl/troubleshooting/).

## Której aplikacji użyć?

- używaj **komputera** do codziennej pracy lokalnej (`bun run electron:dev`)
- używaj **weba** do zdalnego dostępu i przeglądu z telefonu
