# Aktualizacje

Sposób aktualizacji Varin zależy od tego, jak je zainstalowałeś. W każdym przypadku bieżącą wersję sprawdzisz w **Settings → About**.

## Aplikacja na komputer

Aplikacja na komputer sprawdza aktualizacje względem GitHub releases. Gdy jedna jest dostępna, Varin Cię o tym informuje, pobiera ją, gdy wybierzesz, i instaluje przy następnym restarcie. Zawsze masz kontrolę — nic nie instaluje się bez Twojej zgody.

GitHub Releases nie są jeszcze opublikowane. Do tego czasu zaktualizuj checkout źródeł poleceniem `git pull` i przebuduj, albo przypnij przetestowany digest kontenera.

## Web / CLI

Jeśli zainstalowałeś opublikowane CLI, zaktualizuj je z **About** przyciskami sprawdzania i aktualizacji albo z terminala:

```bash
varin update
```

Varin wykrywa, jak zostało zainstalowane (npm, pnpm, yarn albo bun) i uruchamia właściwą aktualizację. Pakiet `@varin/web` nie jest jeszcze w publicznym rejestrze npm, więc ta ścieżka obowiązuje dopiero po publikacji wydania.

Checkouty źródeł aktualizuje się Gitem. Wdrożenia Docker aktualizuje się, pobierając nowy digest obrazu.
