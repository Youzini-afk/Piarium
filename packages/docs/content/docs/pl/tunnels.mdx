# Tunele

Tunel to publiczny link do Twojego Piarium, dzięki któremu możesz dotrzeć do niego ze zwykłej przeglądarki w innej sieci. Użyj `piarium tunnel`, aby utworzyć go dla działającej instancji.

> Łączenie **własnych urządzeń** (aplikacja mobilna, drugi komputer) zwykle nie wymaga tunelu — zamiast tego [sparuj je](/pl/connect-devices/) i pozwól, by szyfrowany end-to-end [Private Relay](/pl/private-relay/) zajął się dostępem spoza domu bez żadnej konfiguracji.

## Wymagania wstępne

Piarium uruchamia CLI dostawcy tunelu na Twoim komputerze. Najpierw zainstaluj dostawcę, którego chcesz użyć:

```bash
brew install cloudflared
brew install ngrok
```

Szybkie tunele Cloudflare działają przez `cloudflared`. Ngrok wymaga konta ngrok i authtokena z panelu ngrok:

```bash
ngrok config add-authtoken <your-ngrok-token>
```

## Szybki start

1. Uruchom Piarium:

```bash
piarium
```

Jeśli pominiesz ten krok, `piarium tunnel start` może automatycznie uruchomić serwer CLI. Przy auto-starcie możesz przekazać opcje serwera, takie jak `--port`, `--host`, `--lan`, `--ui-password` i `--api-only`.

2. Uruchom tunel Cloudflare:

```bash
piarium tunnel start --provider cloudflare --mode quick
```

Albo uruchom tunel Ngrok:

```bash
piarium tunnel start --provider ngrok --mode quick
```

3. Sprawdź status:

```bash
piarium tunnel status
```

Gdy tunel działa, `status` pokazuje publiczny adres URL. Otwórz go lub zeskanuj kod QR, aby dotrzeć do Piarium z dowolnego miejsca.

Domyślnie Piarium wypisuje kod QR w interaktywnych sesjach TTY. Użyj `--qr`, aby wymusić wyświetlenie kodu QR, lub `--no-qr`, aby je wyłączyć.

## Dostawcy

- `cloudflare`: tryby quick, managed remote i managed local
- `ngrok`: tryb quick

## Tryby zarządzane

### Zarządzany zdalny

Użyj tokenu + nazwy hosta zarządzanych przez Cloudflare:

```bash
piarium tunnel start --provider cloudflare --mode managed-remote --token-file ~/.secrets/cf-token --hostname app.example.com
```

### Zarządzany lokalny

Użyj lokalnej konfiguracji `cloudflared`:

```bash
piarium tunnel start --provider cloudflare --mode managed-local --config ~/.cloudflared/config.yml
```

## Profile (managed-remote)

Zapisz profil wielokrotnego użytku:

```bash
piarium tunnel profile add --provider cloudflare --mode managed-remote --name prod-main --hostname app.example.com --token-file ~/.secrets/cf-token
```

Uruchom z zapisanym profilem:

```bash
piarium tunnel start --profile prod-main
```

## Przydatne polecenia

```bash
piarium tunnel providers
piarium tunnel ready --provider cloudflare
piarium tunnel ready --provider ngrok
piarium tunnel doctor --provider cloudflare
piarium tunnel doctor --provider ngrok
piarium tunnel stop --port 3000
```

## Uwagi dotyczące zachowania

- jeden aktywny tunel na instancję Piarium (port)
- uruchomienie nowego trybu/dostawcy na tej samej instancji zastępuje poprzedni tunel
- wygenerowanie nowego linku połączenia unieważnia poprzedni nieużyty
- auto-start tunelu zapisuje flagi serwera, takie jak `--ui-password` i `--api-only`, w ustawieniach instancji używanych przez restarty i aktualizacje
