# Dokumentacja Piarium

Piarium to natywna dla Pi przestrzeń pracy dla agentów programistycznych. Korzysta bezpośrednio z SDK [Pi](https://github.com/earendil-works/pi), drzewa sesji i menedżera pakietów — to nie wrapper terminala ani warstwa zgodności OpenCode.

Skorzystaj z tej dokumentacji, aby:

- zainstalować platformę odpowiednią dla swojego procesu pracy
- otworzyć Piarium do użytku lokalnego lub zdalnego
- dostosować wygląd i rozwiązywać typowe problemy

## Do czego służy Piarium

Piarium jest przeznaczony do tych części programowania z AI, które zyskują na centrum dowodzenia: rozgałęzianie sesji, przeglądanie diffów, zarządzanie terminalami, śledzenie postępu narzędzi, uruchamianie akcji projektu i utrzymywanie całej planszy na widoku, gdy agent pracuje.
