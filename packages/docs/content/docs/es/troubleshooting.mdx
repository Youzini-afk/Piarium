# Resolución de problemas

¿Un contratiempo? Encuentra el síntoma abajo e intenta la solución.

## El comando de Piarium sale o no arranca

- confirma Node.js `>=22.19` (Node.js 24 es la línea base de desarrollo compatible)
- desde una copia del código fuente, ejecuta `bun run dev` o `bun run start:web`
- si tienes una CLI publicada, ejecuta `piarium --version` y reinstala si hace falta

## La UI web no es accesible

- desde una copia del código fuente, lee el terminal que inició `bun run dev`
- si tienes una CLI publicada, revisa los registros del servidor con `piarium logs`
- verifica el puerto activo (el desarrollo usa la URL de Vite; el valor predeterminado del servidor es `3000`)
- abre primero `http://localhost:3000` directamente antes de probar enlaces de túnel

## El enlace remoto/túnel no funciona

- ejecuta `piarium tunnel status --all` cuando la CLI esté instalada
- reinicia el túnel desde la misma instancia/puerto
- regenera el enlace de conexión si el token anterior ya se usó

Consulta [Túneles](/es/tunnels/) para la configuración completa, y [Proxy inverso](/es/reverse-proxy/) si usas uno.

## La extensión de VS Code no se conecta

- confirma que el servidor de Piarium está en ejecución
- vuelve a compilar o actualiza la extensión desde este repositorio
- recarga la ventana de VS Code y reintenta la conexión
