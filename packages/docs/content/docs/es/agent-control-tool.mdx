# Herramienta de control de agentes

Usa la herramienta de control de agentes de Piarium para gestionar el trabajo en la app directamente desde el chat. Está disponible en escritorio y web cuando Piarium ejecuta su runtime local de Pi. No hay una herramienta aparte que instalar ni un comando de shell que ejecutar.

## Qué puedes pedir

Pídeselo al agente en lenguaje natural. Por ejemplo:

- «Crea una sesión nueva de Piarium en este proyecto, usa el modelo `openai/gpt-5.6-sol` y envíale este prompt: revisa el flujo de autenticación.»
- «Crea una sesión nueva de Piarium para esta tarea en un worktree aparte y pídele que añada pruebas para el flujo de inicio de sesión.»
- «Usa Piarium para listar mis 10 sesiones más recientes e incluir su estado actual.»
- «Crea una tarea programada de Piarium llamada Weekday review que envíe este prompt a las 09:00 cada día laborable: revisa los cambios desde la última ejecución.»
- «Ejecuta ahora la tarea programada de Piarium llamada Weekday review.»
- «Revisa la sesión de Piarium llamada Authentication review y muéstrame su última respuesta del asistente.»

La herramienta puede listar proyectos y preferencias de modelo, crear sesiones y darles seguimiento, bifurcar una sesión, crear sesiones de worktree aisladas y gestionar tareas programadas. Las sesiones iniciadas así aparecen en Piarium como cualquier otra, así que puedes abrirlas y continuar el trabajo tú mismo.

## Tenlo en cuenta

- Los prompts de sesión nueva vuelven de inmediato por defecto. Sigue la sesión en Piarium o pide al agente que la compruebe más tarde.
- Solo se crea un worktree aparte cuando lo pides. Los cambios sin commitear de tu worktree actual no se copian.
- La herramienta no puede borrar sesiones ni worktrees, registrar rutas de proyecto, ejecutar comandos de shell arbitrarios ni llamar URL arbitrarias.

## Activar o desactivar la herramienta

Abre **Settings**, cambia **Agent control tool** y guarda. El ajuste se aplica al runtime actual de Piarium.

La herramienta no está disponible dentro de la extensión de VS Code.
