# Instalación

Piarium está en pre-1.0. Las formas compatibles de ejecutarlo hoy son **desde el código fuente** y **con Docker**. Aún no se publican descargas empaquetadas de npm ni de GitHub Release.

Hay tres superficies de producto:

- app de escritorio (Electron)
- app web alojada por el servidor local, que puedes instalar como una app de teléfono (una PWA)
- extensión de VS Code

## Requisitos previos

- Node.js 22.19 o más reciente (Node.js 24 es la línea base de desarrollo)
- [Bun](https://bun.sh) 1.3.14
- Git
- Git for Windows y Git Bash al ejecutar herramientas de shell de Pi en Windows

**No** necesitas una instalación aparte de OpenCode ni de la CLI de Pi. Las compilaciones empaquetadas de escritorio y de contenedor incluyen el runtime de Pi fijado.

## Desde el código fuente (web)

```bash
git clone https://github.com/Youzini-afk/Piarium.git
cd Piarium
bun install --frozen-lockfile
bun run dev
```

Abre la URL de Vite que imprime el terminal. Piarium inicia la UI y el servicio de API/runtime de confianza juntos.

## Desde el código fuente (escritorio)

```bash
bun run electron:dev
```

Más cerca de una compilación empaquetada:

```bash
bun run electron:dev:bundled
```

Se puede construir un instalador de Windows en local con `bun run electron:build:win`. Se esperan instaladores sin firmar hasta que se configuren las credenciales de firma.

## Docker

En un host Docker de Linux:

```bash
mkdir -p data/piarium data/ssh data/cloudflared workspaces
sudo chown -R 1000:1000 data workspaces
umask 077
printf 'PIARIUM_UI_PASSWORD=%s\n' "$(openssl rand -base64 24)" > .env
docker compose up -d
curl --fail http://127.0.0.1:3000/health
```

Abre `http://127.0.0.1:3000` y usa la contraseña generada. Pon un proxy inverso TLS o un túnel aprobado delante de cualquier despliegue expuesto a Internet. En producción, fija `PIARIUM_IMAGE` a un digest probado en lugar de `:latest`.

Compose usa por defecto la imagen ligera `ghcr.io/youzini-afk/piarium-slim:latest` (bastante para el servidor: Bun, Node, Git, SSH y cloudflared). Si el agente necesita compilar Python, Java, Go o Rust dentro del contenedor, aplica la capa de herramientas:

```bash
docker compose -f docker-compose.yml -f docker-compose.toolbelt.yml up -d
```

## VS Code

Compila la extensión desde este repositorio con `bun run vscode:build` / `bun run vscode:package`. Aún no está publicada en el Marketplace.

## Instalador de una línea de CLI (no publicado)

`scripts/install.sh` y `npx @piarium/web` apuntan al paquete npm `@piarium/web`. Ese paquete aún no está en el registro público, así que el instalador curl fallará hasta que se publique una versión. Hasta entonces, usa el código fuente o Docker.
