# Actualizaciones

Cómo actualizas Piarium depende de cómo lo instalaste. En todos los casos puedes ver tu versión actual en **Settings → About**.

## App de escritorio

La app de escritorio comprueba actualizaciones frente a GitHub releases. Cuando hay una disponible, Piarium te avisa, la descarga cuando tú lo eliges y la instala en el siguiente reinicio. Siempre tienes el control: no se instala nada sin tu consentimiento.

Aún no se publican GitHub Releases. Hasta entonces, actualiza una copia del código fuente con `git pull` y vuelve a compilar, o fija un digest de contenedor probado.

## Web / CLI

Si instalaste una CLI publicada, actualízala desde **About** con los botones de comprobar y actualizar, o desde el terminal:

```bash
piarium update
```

Piarium detecta cómo se instaló (npm, pnpm, yarn o bun) y ejecuta la actualización correcta. El paquete `@piarium/web` aún no está en el registro público de npm, así que este camino solo aplica después de publicar una versión.

Las copias del código fuente se actualizan con Git. Los despliegues Docker se actualizan al extraer un nuevo digest de imagen.
