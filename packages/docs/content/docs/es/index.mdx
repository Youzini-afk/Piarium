# Documentación de Piarium

Piarium es un espacio de trabajo nativo de Pi para agentes de programación. Usa directamente el SDK de [Pi](https://github.com/earendil-works/pi), el árbol de sesiones y el gestor de paquetes — no es un envoltorio de terminal ni una capa de compatibilidad de OpenCode.

Usa esta documentación para:

- instalar la app adecuada para tu forma de trabajar
- abrir Piarium para uso local o remoto
- personalizar la apariencia y resolver problemas comunes

## Para qué sirve Piarium

Piarium está pensado para las partes de la programación con IA que se benefician de un centro de control: ramificar sesiones, revisar diffs, gestionar terminales, observar el progreso de las herramientas, ejecutar acciones de proyecto y mantener todo el panel a la vista mientras el agente trabaja.
