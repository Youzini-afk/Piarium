# Inicio rápido

## El camino más rápido

1. Clona [Piarium](https://github.com/Youzini-afk/Piarium) e instala las dependencias con Bun (consulta [Instalación](/es/install/)).
2. Ejecuta `bun run dev`.
3. Abre la URL de Vite que imprime el terminal.
4. Para usarlo desde el teléfono, inicia un [túnel](/es/tunnels/) y escanea el código QR.

Deberías ver la lista de sesiones de Piarium en el navegador. Si carga, ya está en marcha.

Si prefieres un contenedor, usa la ruta Docker de [Instalación](/es/install/) y abre `http://127.0.0.1:3000` con el `PIARIUM_UI_PASSWORD` generado.

Usa una contraseña de UI fuerte, sobre todo si piensas abrir la instancia a Internet.

Si la página no carga, consulta [Resolución de problemas](/es/troubleshooting/).

## ¿Qué app debo usar?

- usa **escritorio** para el trabajo local del día a día (`bun run electron:dev`)
- usa **web** para acceso remoto y revisión desde el teléfono
- usa **VS Code** para sesiones junto a tu código (compila la extensión desde el código fuente)
