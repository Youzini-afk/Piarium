# Variables de entorno

Piarium lee estas variables de entorno al arrancar. Para los servicios de inicio, `piarium startup enable` guarda por defecto una instantánea del entorno actual, así que vuelve a ejecutarlo después de cambiar las variables que quieras que use el servicio.

Piarium incorpora el runtime de Pi. No hay un servidor OpenCode aparte ni variables de integración `OPENCODE_*`.

## Servidor Piarium

### `PIARIUM_HOST`

Dirección de enlace del servidor web de Piarium. Usa `0.0.0.0` para permitir el acceso desde otras máquinas.

### `PIARIUM_UI_PASSWORD`

Contraseña de la UI del navegador. Úsala al enlazar fuera de localhost, al usar túneles o al ejecutar detrás de un proxy inverso.

### `PIARIUM_API_ONLY`

Inicia Piarium en modo headless cuando vale `true` o `1`. Las rutas de API siguen disponibles para clientes de escritorio y móviles, pero no se sirve la UI del navegador.

### `PIARIUM_DATA_DIR`

Sustituye el directorio de datos de Piarium. El valor predeterminado es `~/.config/piarium`.

### `PIARIUM_COMPRESS_API`

Controla la compresión de las respuestas de la API. Usa `true` o `1` para forzarla, `false` o `0` para desactivarla.

### `PIARIUM_SKIP_API_COMPRESSION`

Desactiva la compresión de las respuestas de la API cuando vale `true` o `1`. Tiene prioridad sobre `PIARIUM_COMPRESS_API`.

### `PIARIUM_VERBOSE_REQUEST_LOGS`

Activa registros HTTP detallados cuando vale `true` o `1`.

### `PIARIUM_UPDATE_API_URL`

Sustituye el endpoint de la API de comprobación de actualizaciones. La mayoría de usuarios debería dejarlo sin definir.

### `PIARIUM_PACKAGE_MANAGER`

Fuerza el gestor de paquetes que usan las operaciones de actualización cuando la detección automática se equivoca.

## Terminal y Git

### `PIARIUM_TERMINAL_SHELL`

Ejecutable de shell usado en las sesiones de terminal de Piarium.

### `PIARIUM_GIT_BINARY`

Ejecutable de Git usado por las funciones de Git de Piarium.

### `GIT_BINARY`

Otra sustitución del ejecutable de Git. Prefiere `PIARIUM_GIT_BINARY` para la configuración específica de Piarium.

### `PIARIUM_GIT_READ_CACHE_TTL_MS`

Tiempo de vida, en milisegundos, de las lecturas de archivos respaldadas por Git en caché. Pon `0` para desactivar esta caché al depurar.

## Voz y túneles

### `OPENAI_API_KEY`

Clave de API que usan las funciones de voz de Piarium que llaman a servicios compatibles con OpenAI.

### `PIARIUM_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Permite URL base remotas compatibles con OpenAI para las funciones de voz cuando vale `true` o `1`.

### `NGROK_AUTHTOKEN`

Token de autenticación de ngrok que usan los comandos de túnel de Piarium. También puedes configurar ngrok con `ngrok config add-authtoken <token>`.

## Ayudas de runtime

### `BUN_BINARY`

Ejecutable de Bun que Piarium debe usar al lanzar procesos daemon.

### `BUN_INSTALL`

Raíz de instalación de Bun. Piarium la usa para encontrar `bin/bun` al arrancar el daemon y en las actualizaciones.
