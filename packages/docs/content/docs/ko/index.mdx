# Piarium 문서

Piarium는 코딩 에이전트를 위한 Pi 네이티브 작업 공간입니다. [Pi](https://github.com/earendil-works/pi) SDK, 세션 트리, 패키지 매니저를 직접 사용합니다. 터미널 래퍼도 아니고 OpenCode 호환 레이어도 아닙니다.

이 문서를 사용해:

- 작업 방식에 맞는 앱을 설치하세요
- 로컬 또는 원격 사용을 위해 Piarium를 여세요
- 외관을 맞춤 설정하고 흔한 문제를 해결하세요

## Piarium는 무엇을 위한 것인가

Piarium는 관제 센터가 도움이 되는 AI 코딩 작업을 위한 것입니다. 세션 분기, diff 검토, 터미널 관리, 도구 진행 상황 관찰, 프로젝트 액션 실행, 그리고 에이전트가 작업하는 동안 전체 보드를 한눈에 유지하는 일입니다.
