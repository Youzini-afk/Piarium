# 문제 해결

문제가 생겼나요? 아래 증상을 찾고 해결 방법을 시도하세요.

## Piarium 명령이 종료되거나 시작되지 않음

- Node.js `>=22.19`를 확인하세요(지원되는 개발 기준선은 Node.js 24)
- 소스 체크아웃에서는 `bun run dev` 또는 `bun run start:web`을 실행하세요
- 게시된 CLI가 있다면 `piarium --version`을 실행하고 필요하면 다시 설치하세요

## 웹 UI에 도달할 수 없음

- 소스 체크아웃에서는 `bun run dev`를 시작한 터미널을 읽으세요
- 게시된 CLI가 있다면 `piarium logs`로 서버 로그를 확인하세요
- 활성 포트를 확인하세요(개발은 Vite URL, 서버 기본값은 `3000`)
- 터널 링크를 시험하기 전에 먼저 `http://localhost:3000`을 직접 여세요

## 원격/터널 링크가 동작하지 않음

- CLI가 설치되어 있으면 `piarium tunnel status --all`을 실행하세요
- 같은 인스턴스/포트에서 터널을 다시 시작하세요
- 이전 토큰이 이미 사용되었다면 연결 링크를 다시 생성하세요

전체 설정은 [터널](/ko/tunnels/)을, 리버스 프록시를 쓰는 경우 [리버스 프록시](/ko/reverse-proxy/)를 참고하세요.

## VS Code 확장이 연결되지 않음

- Piarium 서버가 실행 중인지 확인하세요
- 이 저장소에서 확장을 다시 빌드하거나 업데이트하세요
- VS Code 창을 다시 로드한 뒤 연결을 다시 시도하세요
