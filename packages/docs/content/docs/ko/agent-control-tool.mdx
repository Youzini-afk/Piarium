# 에이전트 제어 도구

Piarium 에이전트 제어 도구로 채팅에서 앱 안의 작업을 직접 관리하세요. Piarium가 로컬 Pi 런타임을 실행 중일 때 데스크톱과 웹에서 사용할 수 있습니다. 따로 설치할 도구나 실행할 셸 명령은 없습니다.

## 무엇을 요청할 수 있나요

에이전트에게 평범한 말로 요청하세요. 예를 들어:

- "이 프로젝트에 새 Piarium 세션을 만들고 `openai/gpt-5.6-sol` 모델을 사용한 뒤, 이 프롬프트를 보내세요: 인증 흐름을 검토해 주세요."
- "이 작업을 위해 별도의 worktree에 새 Piarium 세션을 만들고, 로그인 흐름 테스트를 추가하라고 요청하세요."
- "Piarium로 최근 세션 10개를 나열하고 각각의 현재 상태를 포함하세요."
- "Weekday review라는 Piarium 예약 작업을 만들고, 평일마다 09:00에 이 프롬프트를 보내세요: 마지막 실행 이후 변경을 검토해 주세요."
- "Weekday review라는 Piarium 예약 작업을 지금 실행하세요."
- "Authentication review라는 Piarium 세션을 확인하고 최신 어시스턴트 응답을 보여 주세요."

이 도구는 프로젝트와 모델 기본 설정을 나열하고, 세션을 만들고 후속 작업을 하며, 세션을 포크하고, 격리된 worktree 세션을 만들고, 예약 작업을 관리할 수 있습니다. 이렇게 시작한 세션은 다른 세션과 같이 Piarium에 나타나므로, 직접 열고 작업을 이어갈 수 있습니다.

## 알아 둘 점

- 새 세션 프롬프트는 기본적으로 바로 반환됩니다. Piarium에서 세션을 따라가거나, 나중에 에이전트에게 확인을 요청하세요.
- 별도의 worktree는 요청했을 때만 만들어집니다. 현재 worktree의 커밋되지 않은 변경은 복사되지 않습니다.
- 이 도구는 세션이나 worktree를 삭제하거나, 프로젝트 경로를 등록하거나, 임의의 셸 명령을 실행하거나, 임의의 URL을 호출할 수 없습니다.

## 도구 켜기 또는 끄기

**Settings**를 열고 **Agent control tool**을 변경한 뒤 저장하세요. 설정은 현재 Piarium 런타임에 적용됩니다.

이 도구는 VS Code 확장 안에서는 사용할 수 없습니다.
