# 업데이트

Piarium를 업데이트하는 방법은 설치 방식에 따라 다릅니다. 어떤 경우든 **Settings → About**에서 현재 버전을 확인할 수 있습니다.

## 데스크톱 앱

데스크톱 앱은 GitHub releases를 기준으로 업데이트를 확인합니다. 업데이트가 있으면 Piarium가 알려 주고, 사용자가 선택할 때 다운로드하며, 다음 재시작 때 설치합니다. 항상 사용자가 제어합니다. 동의 없이 설치되지 않습니다.

GitHub Releases는 아직 게시되지 않았습니다. 게시되기 전까지는 소스 체크아웃을 `git pull`한 뒤 다시 빌드하거나, 검증된 컨테이너 digest를 고정하세요.

## 웹 / CLI

게시된 CLI를 설치했다면 **About**의 확인 및 업데이트 버튼으로, 또는 터미널에서 업데이트하세요.

```bash
piarium update
```

Piarium는 설치 방식(npm, pnpm, yarn, 또는 bun)을 감지하고 알맞은 업데이트를 실행합니다. `@piarium/web` 패키지는 아직 공개 npm 레지스트리에 없으므로, 이 경로는 릴리스가 게시된 뒤에만 적용됩니다.

소스 체크아웃은 Git으로 업데이트합니다. Docker 배포는 새 이미지 digest를 pull하여 업데이트합니다.
