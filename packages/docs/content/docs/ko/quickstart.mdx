# 빠른 시작

## 가장 빠른 경로

1. [Piarium](https://github.com/Youzini-afk/Piarium)를 클론하고 Bun으로 의존성을 설치하세요([설치](/ko/install/) 참고).
2. `bun run dev`를 실행하세요.
3. 터미널에 출력된 Vite URL을 여세요.
4. 휴대폰에서 쓰려면 [터널](/ko/tunnels/)을 시작하고 QR 코드를 스캔하세요.

브라우저에 Piarium 세션 목록이 보여야 합니다. 로드되면 실행 준비된 것입니다.

컨테이너를 선호하면 [설치](/ko/install/)의 Docker 경로를 사용하고, 생성된 `PIARIUM_UI_PASSWORD`로 `http://127.0.0.1:3000`을 여세요.

특히 인스턴스를 인터넷에 열 계획이라면 강한 UI 비밀번호를 사용하세요.

페이지가 로드되지 않으면 [문제 해결](/ko/troubleshooting/)을 확인하세요.

## 어떤 앱을 써야 하나요?

- 일상적인 로컬 작업에는 **데스크톱**(`bun run electron:dev`)
- 원격 접속과 휴대폰에서 검토할 때는 **웹**
- 코드 바로 옆에서 세션할 때는 **VS Code**(확장을 소스에서 빌드)
