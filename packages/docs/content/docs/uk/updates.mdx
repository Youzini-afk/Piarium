# Оновлення

Спосіб оновлення Varin залежить від того, як ви його встановили. У будь-якому разі поточну версію можна перевірити в **Settings → About**.

## Десктопний застосунок

Десктопний застосунок перевіряє оновлення за GitHub releases. Коли оновлення доступне, Varin повідомляє вас, завантажує його, коли ви обираєте, і встановлює після наступного перезапуску. Контроль завжди за вами — нічого не встановлюється без вашої згоди.

GitHub Releases ще не опубліковано. До того часу оновлюйте checkout вихідного коду командою `git pull` і збирайте знову або закріпіть перевірений digest контейнера.

## Веб / CLI

Якщо ви встановили опубліковану CLI, оновіть її з **About** кнопками перевірки та оновлення або з термінала:

```bash
varin update
```

Varin визначає, як його встановлено (npm, pnpm, yarn або bun), і запускає правильне оновлення. Пакета `@varin/web` ще немає в публічному реєстрі npm, тож цей шлях діє лише після публікації релізу.

Checkout вихідного коду оновлюється через Git. Розгортання Docker оновлюються підтягуванням нового digest образу.
