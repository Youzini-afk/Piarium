# Документація Piarium

Piarium — це нативний для Pi робочий простір для агентів кодування. Він напряму використовує SDK [Pi](https://github.com/earendil-works/pi), дерево сесій і менеджер пакетів — це не обгортка термінала і не шар сумісності OpenCode.

Використовуйте ці доки, щоб:

- встановити застосунок, що пасує вашому робочому процесу
- відкрити Piarium для локального або віддаленого використання
- налаштувати вигляд і усувати типові проблеми

## Для чого Piarium

Piarium створений для тих частин AI-кодингу, яким потрібен командний центр: розгалуження сесій, перегляд діфів, керування терміналами, спостереження за прогресом інструментів, запуск дій проєкту та збереження всієї картини перед очима, поки агент працює.
