# Документація Varin

Varin — це незалежний робочий простір для Agent і повний Harness для програмування, досліджень та інших проєктів. Він містить вбудований runtime Pi та напряму використовує SDK [Pi](https://github.com/earendil-works/pi), дерево сесій і менеджер пакетів, а не обгортку термінала.

Використовуйте ці доки, щоб:

- встановити застосунок, що пасує вашому робочому процесу
- відкрити Varin для локального або віддаленого використання
- налаштувати вигляд і усувати типові проблеми

## Для чого Varin

Varin створений для програмування, досліджень та інших проєктів, яким потрібен командний центр: розгалуження сесій, перегляд результатів, керування терміналами, спостереження за прогресом інструментів, запуск дій проєкту та збереження всієї картини перед очима, поки агент працює.
