# Встановлення

Piarium зараз у pre-1.0. Підтримувані способи запуску сьогодні — **з вихідного коду** та **з Docker**. Пакетовані завантаження npm і GitHub Release ще не опубліковані.

Є три продуктові поверхні:

- десктопний застосунок (Electron)
- вебзастосунок, який хостить локальний сервер і який можна встановити як застосунок на телефоні (PWA)
- розширення VS Code

## Передумови

- Node.js 22.19 або новіший (базова лінія розробки — Node.js 24)
- [Bun](https://bun.sh) 1.3.14
- Git
- Git for Windows і Git Bash, коли запускаєте інструменти оболонки Pi у Windows

Окреме встановлення OpenCode або CLI Pi **не потрібне**. Пакетовані десктопні та контейнерні збірки вже містять зафіксований runtime Pi.

## З вихідного коду (веб)

```bash
git clone https://github.com/Youzini-afk/Piarium.git
cd Piarium
bun install --frozen-lockfile
bun run dev
```

Відкрийте URL Vite, надрукований у терміналі. Piarium запускає UI і довірений сервіс API/runtime разом.

## З вихідного коду (десктоп)

```bash
bun run electron:dev
```

Ближче до пакетованої збірки:

```bash
bun run electron:dev:bundled
```

Інсталятор Windows можна зібрати локально командою `bun run electron:build:win`. Непідписані інсталятори очікувані, доки не налаштовано облікові дані підпису.

## Docker

На Linux-хості Docker:

```bash
mkdir -p data/piarium data/ssh data/cloudflared workspaces
sudo chown -R 1000:1000 data workspaces
umask 077
printf 'PIARIUM_UI_PASSWORD=%s\n' "$(openssl rand -base64 24)" > .env
docker compose up -d
curl --fail http://127.0.0.1:3000/health
```

Відкрийте `http://127.0.0.1:3000` і використайте згенерований пароль. Перед будь-яким розгортанням, доступним з Інтернету, поставте TLS-зворотний проксі або схвалений тунель. У продакшені закріпіть `PIARIUM_IMAGE` на перевіреному digest, а не на `:latest`.

Compose за замовчуванням тягне легкий образ `ghcr.io/youzini-afk/piarium-slim:latest` (достатньо для сервера: Bun, Node, Git, SSH і cloudflared). Якщо агенту треба компілювати Python, Java, Go або Rust у контейнері, накладіть шар інструментів:

```bash
docker compose -f docker-compose.yml -f docker-compose.toolbelt.yml up -d
```

## VS Code

Зберіть розширення з цього репозиторію командами `bun run vscode:build` / `bun run vscode:package`. Його ще не опубліковано в Marketplace.

## Однорядковий інсталятор CLI (не опубліковано)

`scripts/install.sh` і `npx @piarium/web` націлені на npm-пакет `@piarium/web`. Цього пакета ще немає в публічному реєстрі, тож curl-інсталятор падатиме, доки не вийде реліз. До того часу використовуйте вихідний код або Docker.
