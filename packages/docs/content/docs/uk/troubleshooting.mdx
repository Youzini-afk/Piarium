# Усунення несправностей

Щось пішло не так? Знайдіть симптом нижче і спробуйте виправлення.

## Команда Varin завершується або не запускається

- підтвердіть Node.js `>=22.19` (підтримувана базова лінія розробки — Node.js 24)
- з checkout вихідного коду запустіть `bun run dev` або `bun run start:web`
- якщо маєте опубліковану CLI, запустіть `varin --version` і за потреби перевстановіть

## Веб-UI недоступний

- з checkout вихідного коду прочитайте термінал, який запустив `bun run dev`
- якщо маєте опубліковану CLI, перевірте журнали сервера командою `varin logs`
- перевірте активний порт (у розробці використовується URL Vite; типовий порт сервера — `3000`)
- спершу відкрийте `http://localhost:3000` напряму, перш ніж тестувати посилання тунелів

## Віддалене / тунельне посилання не працює

- запустіть `varin tunnel status --all`, коли CLI встановлено
- перезапустіть тунель з того самого інстансу / порту
- згенеруйте посилання підключення знову, якщо попередній токен уже використано

Повне налаштування див. у [Тунелях](/uk/tunnels/), а якщо використовуєте зворотний проксі — у [Зворотному проксі](/uk/reverse-proxy/).
