# Інструмент керування агентом

Використовуйте інструмент керування агентом Piarium, щоб керувати роботою в застосунку безпосередньо з чату. Він доступний на десктопі та вебі, коли Piarium запускає свій локальний runtime Pi. Окремий інструмент установлювати не потрібно, і команду оболонки запускати теж не треба.

## Про що можна попросити

Просіть агента звичайною мовою. Наприклад:

- «Створи нову сесію Piarium у цьому проєкті, використай модель `openai/gpt-5.6-sol` і надішли їй цей промпт: переглянь потік автентифікації.»
- «Створи нову сесію Piarium для цього завдання в окремому worktree і попроси додати тести для потоку входу.»
- «Використай Piarium, щоб показати мої 10 найновіших сесій і включити їхній поточний статус.»
- «Створи заплановане завдання Piarium з назвою Weekday review, яке щобудня о 09:00 надсилає цей промпт: переглянь зміни від останнього запуску.»
- «Запусти зараз заплановане завдання Piarium з назвою Weekday review.»
- «Перевір сесію Piarium з назвою Authentication review і покажи мені її останню відповідь асистента.»

Інструмент може показувати проєкти та вподобання моделей, створювати сесії та продовжувати їх, розгалужувати сесію, створювати ізольовані сесії worktree та керувати запланованими завданнями. Сесії, запущені так, з’являються в Piarium як будь-які інші, тож ви можете відкрити їх і продовжити роботу самостійно.

## Майте на увазі

- Промпти нової сесії за замовчуванням повертаються одразу. Стежте за сесією в Piarium або попросіть агента перевірити її пізніше.
- Окремий worktree створюється лише коли ви просите. Незакомічені зміни з поточного worktree туди не копіюються.
- Інструмент не може видаляти сесії чи worktree, реєструвати шляхи проєктів, запускати довільні команди оболонки чи викликати довільні URL.

## Увімкнути або вимкнути інструмент

Відкрийте **Settings**, змініть **Agent control tool**, потім збережіть. Налаштування застосовується до поточного runtime Piarium.

Інструмент недоступний у розширенні VS Code.
