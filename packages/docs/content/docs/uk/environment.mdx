# Змінні середовища

Piarium читає ці змінні середовища під час запуску. Для служб автозапуску `piarium startup enable` за замовчуванням зберігає знімок поточного середовища, тож запустіть її знову після зміни змінних, які має використовувати служба.

Piarium вбудовує runtime Pi. Окремого сервера OpenCode немає, і змінних інтеграції `OPENCODE_*` теж немає.

## Сервер Piarium

### `PIARIUM_HOST`

Адреса прив’язки вебсервера Piarium. Використовуйте `0.0.0.0`, щоб дозволити доступ з інших машин.

### `PIARIUM_UI_PASSWORD`

Пароль браузерного UI. Використовуйте його, коли прив’язуєте поза localhost, користуєтеся тунелями або працюєте за зворотним проксі.

### `PIARIUM_API_ONLY`

Запускає Piarium у headless-режимі, коли встановлено `true` або `1`. Маршрути API лишаються доступними для десктопних і мобільних клієнтів, але браузерний UI не віддається.

### `PIARIUM_DATA_DIR`

Перевизначає каталог даних Piarium. Типове значення — `~/.config/piarium`.

### `PIARIUM_COMPRESS_API`

Керує стисненням відповідей API. Використовуйте `true` або `1`, щоб примусово ввімкнути, `false` або `0` — щоб примусово вимкнути.

### `PIARIUM_SKIP_API_COMPRESSION`

Вимикає стиснення відповідей API, коли встановлено `true` або `1`. Це має пріоритет над `PIARIUM_COMPRESS_API`.

### `PIARIUM_VERBOSE_REQUEST_LOGS`

Вмикає докладні журнали HTTP-запитів, коли встановлено `true` або `1`.

### `PIARIUM_UPDATE_API_URL`

Перевизначає кінцеву точку API перевірки оновлень. Більшості користувачів варто лишити це невстановленим.

### `PIARIUM_PACKAGE_MANAGER`

Примусово задає менеджер пакетів для операцій оновлення, коли автовизначення помиляється.

## Термінал і Git

### `PIARIUM_TERMINAL_SHELL`

Виконуваний файл оболонки для термінальних сесій Piarium.

### `PIARIUM_GIT_BINARY`

Виконуваний файл Git, який використовують функції Git у Piarium.

### `GIT_BINARY`

Альтернативне перевизначення виконуваного файлу Git. Для конфігурації саме Piarium надавайте перевагу `PIARIUM_GIT_BINARY`.

### `PIARIUM_GIT_READ_CACHE_TTL_MS`

Час життя, у мілісекундах, кешованих читань файлів через Git. Встановіть `0`, щоб вимкнути цей кеш під час налагодження.

## Голос і тунелі

### `OPENAI_API_KEY`

Ключ API, який використовують голосові функції Piarium, що викликають сервіси, сумісні з OpenAI.

### `PIARIUM_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Дозволяє віддалені базові URL, сумісні з OpenAI, для голосових функцій, коли встановлено `true` або `1`.

### `NGROK_AUTHTOKEN`

Токен автентифікації ngrok для команд тунелів Piarium. ngrok також можна налаштувати командою `ngrok config add-authtoken <token>`.

## Допоміжні змінні runtime

### `BUN_BINARY`

Виконуваний файл Bun, який Piarium має використовувати, запускаючи процеси-демони.

### `BUN_INSTALL`

Корінь встановлення Bun. Piarium використовує його, щоб знайти `bin/bun` для запуску демона та оновлень.
