# Швидкий старт

## Найшвидший шлях

1. Клонуйте [Varin](https://github.com/Youzini-afk/Varin) і встановіть залежності за допомогою Bun (див. [Встановлення](/uk/install/)).
2. Запустіть `bun run dev`.
3. Відкрийте URL Vite, надрукований у терміналі.
4. Щоб користуватися з телефона, запустіть [тунель](/uk/tunnels/) і відскануйте QR-код.

У браузері має з’явитися список сесій Varin. Якщо він завантажується, усе готово.

Якщо зручніше з контейнером, скористайтеся шляхом Docker у [Встановленні](/uk/install/) і відкрийте `http://127.0.0.1:3000` зі згенерованим `VARIN_UI_PASSWORD`.

Використовуйте надійний UI-пароль, особливо якщо плануєте відкрити інстанс в інтернет.

Якщо сторінка не завантажується, перевірте [Усунення несправностей](/uk/troubleshooting/).

## Який застосунок обрати?

- використовуйте **десктоп** для щоденної локальної роботи (`bun run electron:dev`)
- використовуйте **веб** для віддаленого доступу та перегляду з телефона
