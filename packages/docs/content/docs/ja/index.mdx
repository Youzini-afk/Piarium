# Piarium ドキュメント

Piarium はコーディングエージェント向けの Pi ネイティブなワークスペースです。[Pi](https://github.com/earendil-works/pi) SDK、セッションツリー、パッケージマネージャーを直接使います。ターミナルのラッパーでも、OpenCode 互換レイヤーでもありません。

このドキュメントでは次のことができます。

- 作業方法に合ったアプリをインストールする
- ローカルまたはリモート利用のために Piarium を開く
- 見た目をカスタマイズし、よくある問題を解決する

- [セキュリティ](/ja/security/) と [トンネル](/ja/tunnels/) — インスタンスを保護し、アクセスする

## Piarium の用途

Piarium は、AI コーディングのうち、管制室があると便利な部分のためのものです。セッションの分岐、差分レビュー、ターミナル管理、ツール進行状況の監視、プロジェクトアクションの実行、エージェントが作業している間に全体の状況を見える状態に保つことができます。
