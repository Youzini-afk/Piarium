# エージェント制御ツール

Piarium のエージェント制御ツールを使い、チャットからアプリ内の作業を直接管理します。Piarium がローカルの Pi ランタイムを実行しているとき、デスクトップと Web で利用できます。別途インストールするツールや、実行するシェルコマンドはありません。

## 依頼できること

エージェントに普通の言葉で頼んでください。例：

- 「このプロジェクトに新しい Piarium セッションを作り、`openai/gpt-5.6-sol` モデルを使い、次のプロンプトを送って：認証フローをレビューして。」
- 「このタスク用に、別の worktree で新しい Piarium セッションを作り、ログインフローのテストを追加するよう依頼して。」
- 「Piarium で最近のセッション 10 件を一覧し、それぞれの現在の状態も含めて。」
- 「Weekday review という名前の Piarium スケジュールタスクを作り、平日の 09:00 に次のプロンプトを送って：前回実行以降の変更をレビューして。」
- 「Weekday review という名前の Piarium スケジュールタスクを今すぐ実行して。」
- 「Authentication review という名前の Piarium セッションを確認し、最新のアシスタント応答を見せて。」

このツールは、プロジェクトとモデル設定の一覧、セッションの作成とフォローアップ、セッションのフォーク、隔離された worktree セッションの作成、スケジュールタスクの管理ができます。この方法で始めたセッションは、他のセッションと同じように Piarium に表示されるので、自分で開いて作業を続けられます。

## 注意点

- 新しいセッションのプロンプトは、デフォルトですぐに戻ります。Piarium でセッションを追うか、あとでエージェントに確認させてください。
- 別の worktree は、依頼したときだけ作成されます。現在の worktree の未コミット変更はコピーされません。
- このツールは、セッションや worktree の削除、プロジェクトパスの登録、任意のシェルコマンド実行、任意の URL 呼び出しはできません。

## ツールのオンとオフ

**Settings** を開き、**Agent control tool** を変更して保存します。設定は現在の Piarium ランタイムに適用されます。

このツールは VS Code 拡張では利用できません。
