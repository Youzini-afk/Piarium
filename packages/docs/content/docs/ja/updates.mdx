# 更新

Piarium の更新方法は、インストール方法によって異なります。どの場合でも、現在のバージョンは **Settings → About** で確認できます。

## デスクトップアプリ

デスクトップアプリは GitHub releases に対して更新を確認します。利用可能な更新があると Piarium が知らせ、あなたが選んだときにダウンロードし、次回の再起動でインストールします。常にあなたが制御します。承諾なしにインストールされることはありません。

GitHub Releases はまだ公開されていません。公開されるまでは、ソースチェックアウトを `git pull` して再ビルドするか、検証済みのコンテナ digest を固定してください。

## Web / CLI

公開済みの CLI をインストールしている場合は、**About** の確認と更新ボタンから、またはターミナルから更新できます。

```bash
piarium update
```

Piarium はインストール方法（npm、pnpm、yarn、または bun）を検出し、適切な更新を実行します。`@piarium/web` パッケージはまだ公開 npm レジストリにないため、この経路はリリース公開後にのみ適用されます。

ソースチェックアウトは Git で更新します。Docker デプロイは新しいイメージ digest を pull して更新します。
