# インストール

Piarium は pre-1.0 です。現在サポートされている実行方法は**ソースから**と **Docker を使う**ことだけです。パッケージ化された npm と GitHub Release のダウンロードはまだ公開されていません。

製品面は 3 つあります。

- デスクトップアプリ（Electron）
- ローカルサーバーがホストする Web アプリ。スマホアプリのようにインストールできます（PWA）
- VS Code 拡張

## 前提条件

- Node.js 22.19 以降（開発の基準は Node.js 24）
- [Bun](https://bun.sh) 1.3.14
- Git
- Windows で Pi のシェルツールを動かす場合は Git for Windows と Git Bash

別途 OpenCode や Pi CLI をインストールする必要は**ありません**。パッケージ化されたデスクトップビルドとコンテナビルドには、固定された Pi ランタイムが含まれます。

## ソースから（Web）

```bash
git clone https://github.com/Youzini-afk/Piarium.git
cd Piarium
bun install --frozen-lockfile
bun run dev
```

ターミナルに表示された Vite URL を開きます。Piarium は UI と信頼できる API/ランタイムサービスを一緒に起動します。

## ソースから（デスクトップ）

```bash
bun run electron:dev
```

パッケージビルドにより近い形：

```bash
bun run electron:dev:bundled
```

Windows インストーラーは `bun run electron:build:win` でローカルにビルドできます。署名用の認証情報が設定されるまでは、未署名のインストーラーが想定どおりです。

## Docker

Linux の Docker ホスト上で：

```bash
mkdir -p data/piarium data/ssh data/cloudflared workspaces
sudo chown -R 1000:1000 data workspaces
umask 077
printf 'PIARIUM_UI_PASSWORD=%s\n' "$(openssl rand -base64 24)" > .env
docker compose up -d
curl --fail http://127.0.0.1:3000/health
```

`http://127.0.0.1:3000` を開き、生成されたパスワードを使います。インターネットに公開するデプロイの前には、TLS リバースプロキシか承認済みのトンネルを置いてください。本番では `PIARIUM_IMAGE` を `:latest` ではなく、検証済みの digest に固定してください。

Compose は既定で軽量イメージ `ghcr.io/youzini-afk/piarium-slim:latest` を使います（サーバーを動かすのに必要な Bun、Node、Git、SSH、cloudflared）。コンテナ内で Python、Java、Go、Rust をコンパイルする必要がある場合は、ツールベルトのオーバーレイを重ねます：

```bash
docker compose -f docker-compose.yml -f docker-compose.toolbelt.yml up -d
```

## VS Code

このリポジトリから `bun run vscode:build` / `bun run vscode:package` で拡張をビルドします。Marketplace にはまだ公開されていません。

## CLI ワンライナー（未公開）

`scripts/install.sh` と `npx @piarium/web` は `@piarium/web` npm パッケージを対象にしています。そのパッケージはまだ公開レジストリにないため、リリースが公開されるまで curl インストーラーは失敗します。それまではソースまたは Docker を使ってください。
