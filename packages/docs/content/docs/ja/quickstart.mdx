# クイックスタート

## いちばん早い手順

1. [Piarium](https://github.com/Youzini-afk/Piarium) をクローンし、Bun で依存関係をインストールします（[インストール](/install/) を参照）。
2. `bun run dev` を実行します。
3. ターミナルに表示された Vite URL を開きます。
4. スマホから使う場合は、[トンネル](/tunnels/) を開始して QR コードをスキャンします。

ブラウザに Piarium のセッション一覧が表示されるはずです。読み込めれば、起動は完了です。

コンテナの方がよければ、[インストール](/install/) の Docker 手順を使い、生成された `PIARIUM_UI_PASSWORD` で `http://127.0.0.1:3000` を開きます。

特にインターネットへ公開する予定がある場合は、強い UI パスワードを使ってください。

ページが読み込まれない場合は [トラブルシューティング](/troubleshooting/) を確認してください。

## どのアプリを使うべきか

- 日常のローカル作業には **デスクトップ**（`bun run electron:dev`）
- リモートアクセスやスマホからのレビューには **Web**
- コードのすぐ横でセッションするなら **VS Code**（拡張をソースからビルド）
