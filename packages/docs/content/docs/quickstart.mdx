# Quickstart

## Fastest path

1. Clone [Piarium](https://github.com/Youzini-afk/Piarium) and install dependencies with Bun (see [Install](/install/)).
2. Run `bun run dev`.
3. Open the Vite URL printed in the terminal.
4. To use it from your phone, start a [tunnel](/tunnels/) and scan the QR code.

You should see the Piarium session list in your browser. If it loads, you're up and running.

If you prefer a container, use the Docker path on [Install](/install/) and open `http://127.0.0.1:3000` with the generated `PIARIUM_UI_PASSWORD`.

Use a strong UI password, especially if you plan to open the instance to the internet.

If the page doesn't load, check [Troubleshooting](/troubleshooting/).

## Which app should I use?

- use **desktop** for day-to-day local work (`bun run electron:dev`)
- use **web** for remote access and reviewing from your phone
- use **VS Code** for sessions right next to your code (build the extension from source)
