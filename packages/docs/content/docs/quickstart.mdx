# 快速开始

## 最快路径

1. 克隆 [Piarium](https://github.com/Youzini-afk/Piarium)，并用 Bun 安装依赖（见[安装](/install/)）。
2. 运行 `bun run dev`。
3. 打开终端中打印的 Vite URL。
4. 想在手机上使用，启动一个[隧道](/tunnels/)并扫描二维码。

你应该会在浏览器中看到 Piarium 会话列表。如果它能加载出来，说明你已经成功运行起来了。

如果更喜欢容器，请使用[安装](/install/)中的 Docker 路径，并用生成的 `PIARIUM_UI_PASSWORD` 打开 `http://127.0.0.1:3000`。

请使用强 UI 密码，尤其是当你打算将实例开放到互联网时。

如果页面无法加载，请查看[问题排查](/troubleshooting/)。

## 我应该使用哪个应用？

- 日常本地工作使用 **桌面**（`bun run electron:dev`）
- 远程访问和在手机上审查时使用 **Web**
- 在代码旁进行会话时使用 **VS Code**（从源码构建扩展）
