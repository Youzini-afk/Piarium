# Troubleshooting

Hit a snag? Find the symptom below and try the fix.

## Piarium command exits or fails to start

- confirm Node.js `>=22.19` (Node.js 24 is the supported development baseline)
- from a source checkout, run `bun run dev` or `bun run start:web`
- if you have a published CLI, run `piarium --version` and reinstall if needed

## Web UI is not reachable

- from a source checkout, read the terminal that started `bun run dev`
- if you have a published CLI, check server logs with `piarium logs`
- verify the active port (development uses the Vite URL; the server default is `3000`)
- open `http://localhost:3000` directly first before testing tunnel links

## Remote/tunnel link does not work

- run `piarium tunnel status --all` when the CLI is installed
- restart the tunnel from the same instance/port
- regenerate the connect link if the previous token was already used

See [Tunnels](/en/tunnels/) for the full setup, and [Reverse Proxy](/en/reverse-proxy/) if you run one.

## VS Code extension does not connect

- confirm the Piarium server is running
- rebuild or update the extension from this repository
- reload the VS Code window and retry the connection
