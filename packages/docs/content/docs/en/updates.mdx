# Updates

How you update Piarium depends on how you installed it. In every case you can check your current version at **Settings → About**.

## Desktop app

The desktop app checks for updates against GitHub releases. When one is available, Piarium tells you, downloads it when you choose, and installs it on the next restart. You're always in control — nothing installs without your say-so.

GitHub Releases are not published yet. Until they are, update a source checkout with `git pull` and rebuild, or pin a tested container digest.

## Web / CLI

If you installed a published CLI, update it from **About** with the check and update buttons, or from the terminal:

```bash
piarium update
```

Piarium detects how it was installed (npm, pnpm, yarn, or bun) and runs the right update for you. The `@piarium/web` package is not on the public npm registry yet, so this path applies only after a release is published.

Source checkouts update with Git. Docker deployments update by pulling a new image digest.
