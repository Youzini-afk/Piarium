# Agent Control Tool

Use the Piarium agent-control tool to manage work in the app directly from chat. It is available on desktop and web when Piarium is running its local Pi runtime. There is no separate tool to install or shell command to run.

## What you can ask

Ask the agent in plain language. For example:

- "Create a new Piarium session in this project, use the `openai/gpt-5.6-sol` model, and send it this prompt: review the authentication flow."
- "Create a new Piarium session for this task in a separate worktree, and ask it to add tests for the login flow."
- "Use Piarium to list my 10 most recent sessions and include their current status."
- "Create a Piarium scheduled task named Weekday review that sends this prompt at 09:00 every weekday: review changes since the last run."
- "Run the Piarium scheduled task named Weekday review now."
- "Check the Piarium session named Authentication review and show me its latest assistant response."

The tool can list projects and model preferences, create and follow up on sessions, fork a session, create isolated worktree sessions, and manage scheduled tasks. Sessions started this way appear in Piarium like any other session, so you can open them and continue the work yourself.

## Keep in mind

- New session prompts return immediately by default. Follow the session in Piarium, or ask the agent to check it later.
- A separate worktree is only created when you ask for one. Uncommitted changes from your current worktree are not copied into it.
- The tool cannot delete sessions or worktrees, register project paths, run arbitrary shell commands, or call arbitrary URLs.

## Turn the tool on or off

Open **Settings**, change **Agent control tool**, then save. The setting applies to the current Piarium runtime.

The tool is not available inside the VS Code extension.
